條文

第一條

第一條接案範圍

本所承辦民事、勞資及商務三類事務。本說明書所稱「六種情況」，指下列各款：

  1. 租賃：押金、修繕、提前終止、點交及欠租。
  2. 勞資：資遣、解僱、加班費、職業災害補償及非自願離職證明。
  3. 車禍：財物損失與人身傷害之和解、調解及求償。
  4. 繼承：遺產分割、拋棄繼承、遺囑之作成與執行。
  5. 合約：買賣、承攬、租賃、合作、授權與競業條款之審閱。
  6. 公司：有限公司及股份有限公司之設立、章程與股東協議。

下列事務本所不承辦，於第一次諮詢時告知並轉介：刑事辯護、智慧財產訴訟、跨境仲裁、移民及稅務爭訟。

批

先看這一條：你的事在不在六種裡面。不在的話，第一次談完也會告訴你該去找誰。

第二條

第二條第一次諮詢

第一次諮詢以六十分鐘為一單位，面談、視訊或電話擇一。

  1. 前二十分鐘由委任人陳述經過；律師只聽、不打斷，並當場整理成時間表。
  2. 接著由律師說明法律上的爭點、可能的處理途徑，以及各途徑所需的時間與費用。
  3. 最後十分鐘決定下一步：自行處理、聲請調解，或委任本所。三者皆可；不委任，不另收費用。

諮詢結束後三個工作日內，本所寄出一頁書面摘要，載明爭點、建議步驟與應補文件。

批

六十分鐘談完，不一定要委任。那一頁摘要是給你帶走的，拿去問別家也可以。

第三條

第三條租賃糾紛

常見爭點：押金返還、修繕責任歸屬、提前終止之違約金、點交時之損壞認定、欠租之催告與終止。

第一次諮詢請攜帶（可勾選）：

  • 租賃契約正本或影本，含附件與點交清單。
  • 與房東或房客之對話紀錄；通訊軟體截圖請保留日期。
  • 租金與押金之匯款紀錄。
  • 屋況照片，入住時與退租時各一組為佳。

處理途徑依序為：存證信函、鄉鎮市區調解委員會、民事訴訟。租金與押金之爭議多屬小額或簡易程序，自起訴至判決通常在六個月內。

批

押金依法最多兩個月租金，多收的可以要回來。照片有沒有日期，差很多。

第四條

第四條勞資爭議

常見爭點：資遣費與預告工資之計算、加班費、特別休假未休之折算、非自願離職證明之開立、競業禁止條款之效力。

第一次諮詢請攜帶（可勾選）：

  • 勞動契約或聘僱通知書、工作規則。
  • 最近十二個月之薪資單與出勤紀錄；打卡紀錄得向雇主請求提供。
  • 離職相關之書面通知或對話紀錄。

處理途徑：先向勞動局申請勞資爭議調解（不收費，約三十日內召開）；調解不成立，再提起勞動訴訟。本所會先試算金額，由你決定值不值得走下去。

批

先去勞工局調解，不用錢。數字算清楚再決定要不要告；很多案件在調解那一關就結束了。

第五條

第五條車禍理賠

常見爭點：肇事責任比例、醫療費與工作損失之計算、車輛修復費與折舊、精神慰撫金、保險公司之代位求償。

第一次諮詢請攜帶（可勾選）：

  • 道路交通事故當事人登記聯單、現場圖及初步分析研判表；研判表於事故後約三十日可向警察機關申請。
  • 診斷證明書、醫療費用收據、請假證明。
  • 車輛估價單或修復發票、行車紀錄器影像。
  • 雙方之強制險與任意險保單資料。

處理途徑：先由保險公司協商；協商不成，聲請調解；涉及過失傷害者，請注意自知悉行為人起六個月之告訴期間。

批

六個月的告訴期間要記住，從知道對方是誰那天開始算。研判表還沒出來之前，先把每一張收據留著。

告訴期間怎麼算知悉對方是誰
起算六個月內
提出告訴
第六條

第六條遺產繼承

常見爭點：繼承人之範圍、特留分、遺囑之效力、生前贈與之歸扣、不動產之分割方式、被繼承人所遺之債務。

第一次諮詢請攜帶（可勾選）：

  • 被繼承人之除戶戶籍謄本及各繼承人之戶籍謄本。
  • 向國稅局申請之財產、所得及金融遺產清單。
  • 遺囑、保單、不動產權狀（如有）。

應注意之期限：拋棄繼承應於知悉得繼承之時起三個月內向法院聲明；遺產稅之申報期限為被繼承人死亡之日起六個月。

處理途徑：繼承系統表、遺產分割協議；無法協議時，向法院聲請調解或提起分割遺產之訴。

批

三個月、六個月，兩個期限先寫在月曆上。協議分割通常比打官司快一年以上。

兩個期限知悉
起算三個月內
拋棄繼承六個月內
遺產稅申報
第七條

第七條合約審閱

審閱範圍：買賣、承攬、租賃、合作、授權、保密及競業禁止條款；以中文契約為原則，英文契約另行報價。

交付內容：

  1. 逐條批註版：在原契約上以紅字標示風險條款及修改建議。
  2. 一頁風險表：依「必改、建議改、可接受」三級排列。
  3. 三十分鐘說明：面談或視訊擇一。

時程：十頁以內三個工作日，每增加十頁加計一個工作日；要求二十四小時內交付者，費用加計五成。

批

紅字是本所的意見，對方不一定會同意。帶著風險表去談，至少知道哪幾條不能讓。

第八條

第八條設立公司

服務範圍：組織型態之選擇（有限公司或股份有限公司）、公司名稱預查、章程擬定、股東協議、設立登記及稅籍登記。

請準備（可勾選）：

  • 全體股東之身分證明文件影本及出資比例。
  • 公司所在地之房屋使用同意書或租賃契約。
  • 預定之公司名稱三個，依優先順序排列。

時程：自名稱預查核准之日起，約十至十五個工作日完成登記；股東協議另行約定時程。

本所不代辦會計及記帳事務；登記完成時提供合作會計師名單，由委任人自行選擇。

批

名稱預查先做，撞名就省下重跑一趟。股東協議在感情好的時候簽，最便宜。

第十條

第十條委任與終止

委任以書面為之。本所於收受委任契約及首期費用後開始工作。

委任人得隨時終止委任。本所於委任人未依約付款、要求為違法之行為，或發生利益衝突時，得終止委任，並以書面通知。

委任終止後，本所於十個工作日內返還委任人交付之文件正本，並結算費用。

批

想停就可以停，文件會還你。本所也可能主動停，但會寫清楚為什麼。

第十一條

第十一條保密

委任人於諮詢及委任期間揭露之一切事實與文件，本所依律師法負保密義務，不因委任終止而消滅。

未受委任之諮詢，亦適用前項之規定。

批

只來談過一次、沒有委任，說過的話一樣不會出這扇門。

第十二條

第十二條一般性說明

本說明書之內容為一般性說明，不構成對任何個案之法律意見。個案之處理結果取決於事實、證據與法院之判斷，本所不保證任何結果。

法規與實務見解可能變動；以諮詢當日之說明為準。

批

這一頁幫你知道要帶什麼、要花多少；你的案子怎麼走，要坐下來談過才知道。
