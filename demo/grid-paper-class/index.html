批改範文第二頁

停電的晚上

四年級　陳宥均

上個星期三晚上，我正在寫數學作業，寫到第七題的時候，燈突然「啪」一聲全部熄掉了。我以為是我把燈弄壞了，嚇得不敢動。媽媽從廚房喊：「停電了！大家不要走動！」

爸爸用手機照路，去陽台找出一支很久很久沒用的手電筒，可是電池早就沒電了。最後我們點了阿嬤拜拜用的紅蠟燭。燭光一直晃，我們的影子在牆上變得好大，像三個巨人在開會。

格子語文教室二

沒有電視也沒有平板，我們就坐在客廳聊天。爸爸說他小時後候常停電，大家會到樓下乘涼、講鬼故事。我問弟弟怕不怕，他說不怕，可是他的手一直緊緊的地抓著我的衣服。

電來的時候，冰箱先「嗡」了一聲，然後燈全亮了。大家都說「喔——」，好像有一點可惜。弟弟馬上就放開我的衣服。那天晚上我才發現，沒有電的時候，我們家會變得比平常更安靜，也更靠近。

總評宥均：從一個「啪」開始，到一個「嗡」結束，中間的黑暗寫得很熱鬧。第三段爸爸的小時候，可以再多寫一兩句他講的鬼故事，讓讀的人也跟著進去。弟弟放開衣服那一句，比「可惜」更可惜，寫得好。

老師的旁批

  1. 用聲音寫停電，一下子就有畫面。
  2. 一次就夠。寫兩次，反而不急了。
  3. 影子變巨人、晃動變開會，兩層都想到了。
  4. 時候的「候」。
  5. 修飾動作，用「地」。
  6. 補一個字，句子才落地。
  7. 結尾不喊口號，很好。

林雨蓁中年級班

紅筆只圈不劃。孩子寫錯字，她圈起來，把對的字寫在格子上面，等孩子自己改。教了十二年國小國語，她說三、四年級最要緊的是先寫出來。

那隻狗的毛很柔軟，摸起來像綿棉被。

格子語文教室四

吳佩璇高年級班

最愛畫波浪線。她說讓孩子知道哪句寫對了，比指出錯字更重要；一篇作文至少找三句畫。帶過六屆畢業班。

外婆的手像一塊老薑，熱熱的，有點粗。

周承恩國中班

旁批寫得最多。他會把孩子的句子改寫一次，兩句並排著比，讓孩子自己選。國文系畢業，教國中作文九年。

我覺得這件事情讓我很感動。
